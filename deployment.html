Checklist

Before you start

Cost and security.

Costs

AWS may charge for S3 storage, requests and CloudFront data transfer. A small site is usually inexpensive and may fall within free tiers, but prices change, so check the AWS pricing pages and set a billing alert. Delete resources when you finish.

Security

  • Keep the bucket private and use Origin Access Control.
  • Never put AWS access keys in website code. This project contains none.
  • HTTPS protects the connection to CloudFront. It does not make the website content secret.
  • Optionally add a CloudFront response headers policy for security headers.

REST endpoint or website endpoint

The S3 REST endpoint works with Origin Access Control and a private bucket. The S3 website endpoint needs a public bucket and only supports HTTP to S3. This project uses the REST endpoint.

Custom domain

The default CloudFront domain works with no extra setup. A custom domain needs its own certificate (AWS Certificate Manager, region us-east-1) and DNS changes.
