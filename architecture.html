Hit or miss

Two outcomes.

Cache miss. The first time anyone requests a file, the edge has no copy. CloudFront fetches it from S3, keeps a copy and returns it.

Cache hit. Later requests for the same file are answered by the edge. S3 is not contacted, which reduces waiting and origin traffic.

How long a copy stays cached depends on cache settings and TTL. After you upload a changed file, create an invalidation so edges drop old copies.

Key terms

Four ideas to know.

Amazon S3

Object storage. Files live in buckets and are private by default. It is the origin that holds the real files.

CDN

A content delivery network keeps copies of files at edge locations near users. CloudFront is the AWS CDN.

HTTPS

HTTP protected by TLS encryption. The default CloudFront domain provides a certificate, so the browser shows a padlock.

Origin Access Control

Lets CloudFront, and only CloudFront, read the private S3 bucket. The bucket never needs to be public.
